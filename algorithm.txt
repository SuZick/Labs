АЛГОРИТМ РАБОТЫ ПРОГРАММЫ: "СТЕКИ И ОЧЕРЕДИ"

I. ОПИСАНИЕ ЗАДАЧИ
Программа демонстрирует работу со структурами данных "Стек" (LIFO - Last In, First Out)
и "Очередь" (FIFO - First In, First Out), реализованными двумя способами:
на основе массивов и на основе связных списков.

II. СТРУКТУРЫ ДАННЫХ

1. Стек на основе массива (ArrayStack)
   Поля:
     - Массив целых чисел фиксированного размера для хранения данных
     - Индекс вершины стека (изначально -1)
   Операции:
     Добавление элемента (Push):
       1. Увеличить индекс вершины на 1
       2. Записать элемент в позицию с новым индексом
     Извлечение элемента (Pop):
       1. Проверить, не пуст ли стек (индекс < 0)
       2. Если пуст - вернуть признак ошибки
       3. Сохранить значение элемента на вершине
       4. Уменьшить индекс вершины на 1
       5. Вернуть сохраненное значение
     Вычисление суммы:
       1. Инициализировать переменную суммы нулем
       2. Пройти по всем элементам от начала до вершины
       3. Прибавить каждый элемент к сумме
       4. Вернуть результат

2. Очередь на основе массива (ArrayQueue)
   Поля:
     - Массив целых чисел фиксированного размера
     - Счётчик текущего количества элементов
   Операции:
     Добавление элемента (Enqueue):
       1. Записать элемент в позицию, равную счётчику
       2. Увеличить счётчик на 1
     Извлечение элемента (Dequeue):
       1. Проверить, не пуста ли очередь
       2. Если пуста - вернуть признак ошибки
       3. Сохранить первый элемент массива
       4. Сдвинуть все оставшиеся элементы влево на одну позицию
       5. Уменьшить счётчик на 1
       6. Вернуть сохраненное значение

3. Узел связного списка (Node)
   Поля:
     - Целочисленное значение
     - Ссылка на следующий узел

4. Стек на основе связного списка (LinkedStack)
   Поля:
     - Ссылка на верхний узел (вершину стека)
   Операции:
     Добавление элемента (Push):
       1. Создать новый узел с заданным значением
       2. Установить ссылку нового узла на текущую вершину
       3. Сделать новый узел вершиной стека
     Извлечение элемента (Pop):
       1. Проверить, не пуст ли стек (вершина = null)
       2. Если пуст - вернуть признак ошибки
       3. Сохранить значение вершины
       4. Переместить указатель вершины на следующий узел
       5. Освободить память удалённого узла
       6. Вернуть сохраненное значение
     Вычисление суммы:
       1. Инициализировать переменную суммы нулем
       2. Установить текущий узел на вершину
       3. Пока текущий узел не null:
            - Прибавить значение узла к сумме
            - Перейти к следующему узлу
       4. Вернуть результат

5. Очередь на основе связного списка (LinkedQueue)
   Поля:
     - Ссылка на первый узел (начало очереди)
     - Ссылка на последний узел (конец очереди)
   Операции:
     Добавление элемента (Enqueue):
       1. Создать новый узел с заданным значением
       2. Если очередь пуста:
            - Сделать новый узел и началом, и концом очереди
       3. Иначе:
            - Присоединить новый узел к концу очереди
            - Обновить указатель конца на новый узел
     Извлечение элемента (Dequeue):
       1. Проверить, не пуста ли очередь (начало = null)
       2. Если пуста - вернуть признак ошибки
       3. Сохранить значение первого узла
       4. Переместить указатель начала на следующий узел
       5. Если начало стало null - обнулить и конец
       6. Освободить память удалённого узла
       7. Вернуть сохраненное значение

III. ОСНОВНОЙ АЛГОРИТМ РАБОТЫ

Этап 1: Решение на основе массивов (solveWithArrays)

1. Инициализация генератора случайных чисел
   - Использовать текущее время в качестве "зерна" для генерации

2. Формирование исходного стека:
   1. Создать пустой стек
   2. Сгенерировать случайное количество элементов (от 3 до 8)
   3. Для каждого элемента:
        - Сгенерировать случайное число от 1 до 20
        - Добавить число в стек
        - Вывести сообщение о добавлении

3. Формирование исходной очереди:
   1. Создать пустую очередь
   2. Сгенерировать случайное количество элементов (от 3 до 8)
   3. Для каждого элемента:
        - Сгенерировать случайное число от 1 до 20
        - Добавить число в очередь
        - Вывести сообщение о добавлении

4. Вывод исходных данных:
   - Вывести содержимое стека
   - Вывести содержимое очереди

5. Вычисление суммы элементов стека:
   - Вызвать метод подсчета суммы
   - Вывести результат

6. Обработка очереди и формирование нового стека:
   1. Создать новый пустой стек для результата
   2. Создать временную очередь для сохранения исходных данных
   3. Пока исходная очередь не пуста:
        - Извлечь элемент из очереди
        - Добавить элемент во временную очередь (для сохранения)
        - ПРОВЕРКА УСЛОВИЯ: если сумма стека НЕ делится нацело на текущий элемент:
            * Добавить элемент в новый стек
            * Вывести сообщение о добавлении
        - Иначе:
            * Пропустить элемент
            * Вывести сообщение о пропуске

7. Восстановление исходной очереди:
   1. Пока временная очередь не пуста:
        - Извлечь элемент из временной очереди
        - Добавить его обратно в исходную очередь

8. Вывод результатов:
   - Вывести исходный стек
   - Вывести исходную очередь
   - Вывести новый результирующий стек

Этап 2: Решение на основе связных списков (solveWithLinkedLists)

Алгоритм полностью идентичен этапу 1, но использует реализации структур данных
на основе связных списков вместо массивов.

Последовательность шагов:
  1. Вывести заголовок о начале работы с динамическими списками
  2. Сформировать стек (аналогично п. 2 этапа 1)
  3. Сформировать очередь (аналогично п. 3 этапа 1)
  4. Вывести исходные данные
  5. Вычислить сумму элементов стека
  6. Обработать очередь и создать новый стек (аналогично п. 6 этапа 1)
  7. Восстановить исходную очередь
  8. Вывести результаты

Главная функция (main):
  1. Инициализировать генератор случайных чисел (srand)
  2. Вывести заголовок программы
  3. Вызвать функцию решения на массивах
  4. Вызвать функцию решения на связных списках
  5. Завершить работу программы
