# Лабораторная работа №1: Линейные списки

## Задание

Даны стек и очередь целых чисел. Из элементов очереди, на которые не делится сумма элементов стека, сформировать новый стек.

## Требования

1. Количество элементов исходных линейных списков заранее не определено и задается случайным образом. При дальнейшей обработке считается, что количество элементов списка не известно, т.е. обработка производится, пока не достигнут конец списка.

2. Программа должна сформировать исходные линейные списки, вывести их содержимое на экран (при этом данные из списков не должны быть потеряны), произвести обработку и вывести содержимое итогового списка на экран.

## Реализация

Задание выполнено двумя способами:

### а) Реализация на массивах (`lab1_arrays.cpp`)

- **Стек**: Реализован на основе статического массива с указателем на вершину стека
- **Очередь**: Реализована на основе кольцевого массива с указателями на начало и конец

### б) Реализация на динамических списках (`lab1_lists.cpp`)

- **Стек**: Реализован на основе односвязного списка, вершина стека - первый элемент списка
- **Очередь**: Реализована на основе односвязного списка с указателями на начало и конец очереди

## Алгоритм работы программы

1. **Инициализация**: Генерируются случайное количество элементов для стека (от 3 до 10) и очереди (от 5 до 14)

2. **Заполнение**: Стек и очередь заполняются случайными целыми числами от 1 до 50

3. **Вывод исходных данных**: На экран выводятся содержимое стека и очереди

4. **Обработка**:
   - Вычисляется сумма всех элементов стека
   - Для каждого элемента очереди проверяется: делится ли сумма элементов стека на этот элемент
   - Если НЕ делится (остаток от деления не равен нулю), элемент добавляется в новый стек

5. **Вывод результата**: На экран выводится содержимое нового стека

6. **Проверка сохранности**: Выводятся исходные данные, подтверждая что они не были изменены в процессе обработки

## Особенности реализации

### Массивы:
- Фиксированный максимальный размер (100 элементов)
- Быстрый доступ к элементам по индексу
- Ограничение по размеру
- Простая реализация

### Динамические списки:
- Неограниченный размер (зависит от доступной памяти)
- Динамическое выделение памяти
- Автоматическое освобождение памяти в деструкторах
- Более гибкая структура данных

## Требования к системе

- Компилятор C++ с поддержкой стандарта C++11 или выше (g++, clang++)
- Make (опционально, для использования Makefile)
- Операционная система: Linux, macOS, Windows (с MinGW или WSL)
